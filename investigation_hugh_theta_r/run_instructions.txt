Run from this folder as the working directory.

Commands
1. python scripts\bootstrap_balanced_theta_vs_r_recording_level.py
2. python scripts\compare_25nm_40nm_new_method_recording_bootstrap.py

What they do
- Step 1 reads the copied raw rod folders:
  - tumbling 25nm glycerol\pending, good, bad
  - glycerol suspended rods 17062026\pending, good, bad
- It builds the balanced-sampling theta(r) curves with recording-bootstrap errors and writes the outputs into:
  - tumbling 25nm glycerol\plots\balanced_phi_xy_points
  - glycerol suspended rods 17062026\plots\balanced_phi_xy_points_all_recordings
- Step 2 makes the combined 25 nm vs 40 nm comparison plot in:
  - tumbling 25nm glycerol\plots\balanced_phi_xy_points

Directories to set in the code
- None, if you run from this package folder.
- The scripts use relative paths and are already set up for this package layout.

Requirements
- Python with numpy and matplotlib.
- scipy is optional; if present it uses PCHIP interpolation, otherwise it falls back to numpy interpolation.
